# PLAN 术语与网页检索规则

## L0 术语

- `qid`：一次可独立执行和登记状态的查询标识；不是某条专利的标识。
- `query`：本次技术检索表达；`prompt`：用户粘贴到智慧芽 Agent 的完整指令。
- `required`：该查询是否属于本轮必要覆盖范围；未执行必需查询会使覆盖未完成。
- `fids`：查询针对的技术特征编号；查询中提到某个词不等于证明该特征。
- 零命中：查询已成功执行且结果为零。截断：存在结果但当前展示或导出没有包含全部结果。

## L1 规则、来源与适用范围

来源：用户设计稿第二、五、七节，以及用户本次明确的“无专利 API，使用智慧芽 Agent 网页提示词并提供 PDF”约束。适用于本地首版的人工采集模式。

- 查询必须绑定特征，不用与需求无关的热词增加召回量。
- 数据采集由用户完成；本程序保留原始文件和源行，记录实际导出日期，不虚构网页自动化或分页能力。
- 需要分类号时，仅采用已核对官方名称与范围的 IPC/CPC；未经核实的分类号不得当作必需限制。
- 零命中、截断、失败分开登记。截断需拆查询或继续导出；失败需记录实际原因，不能写成“没有相关专利”。

## 提示词内容

每条提示词应包含：检索目的；本条特征及同义词；关键关系；规格允许的日期和文献范围；要求返回实际检索式、总结果数、导出上限；要求导出的公开号、申请号、标题、申请人、公开日、申请日、优先权日、文献类型、法律状态、摘要、详情链接（可取得时带同族信息）。

说明“不能确认的字段留空，不推断”。所需导出字段不意味着平台一定提供；缺字段由本地程序按 UNKNOWN 处理。申请号与公开号不要混在同一列。每条必需查询都应对应一次导入记录；实际查询内容变更后保存新的查询，不能用旧编号掩盖变化。

## L5–L6 参数

默认每轮最多 12 条查询，最多 2000 篇候选，实际以任务包配置为准。必需查询执行率 = 已成功执行的必需查询数 / 必需查询数；截断或失败仍属未完成覆盖。新增量按去重后的文献计，不用源文件行数充数。
